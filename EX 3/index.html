04 — About

The idea behind the tree

What is a Minimum Spanning Tree?

A Minimum Spanning Tree connects every vertex in a weighted graph using the smallest possible total edge weight, with no cycles and exactly V−1 edges for V vertices. It's the cheapest way to keep everything connected.

Kruskal's Algorithm

Kruskal's builds the tree by considering edges globally, cheapest first, and skipping any edge that would connect two vertices already in the same component — detected in near-constant time with Union-Find.

Prim's Algorithm

Prim's builds the tree locally: starting from one vertex, it repeatedly extracts the cheapest edge leading to a vertex outside the current tree, using a priority queue to always know what's cheapest next.

Where MSTs show up

  • Road network design
  • Internet routing backbones
  • Electric power distribution
  • Computer network layout
  • Water pipeline systems
