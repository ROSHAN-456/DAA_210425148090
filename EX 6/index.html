About the Reactor

AI Matrix Optimizer reframes the classic Matrix Chain Multiplication Dynamic Programming problem as a cinematic AI energy reactor. Every matrix becomes a module, every multiplication becomes a fusion, and every table cell becomes a decision the AI core commits to memory — so it is never solved twice.

Built with vanilla HTML5, CSS3, ES6 JavaScript and Chart.js — no frameworks, no backend, just an algorithm made visible.
