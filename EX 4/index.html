About Dijkstra's Algorithm

The classic single-source shortest path algorithm, powering everything from GPS navigation to internet routing.

🧭

What is Dijkstra's Algorithm?

A greedy algorithm that finds the shortest path from a single source vertex to every other vertex in a weighted graph with non-negative edge weights, by always expanding the closest unvisited vertex next.

📥

How the Priority Queue Works

Every vertex is tracked with its current best-known distance. The priority queue always hands over the unvisited vertex with the smallest distance, guaranteeing that once a vertex is extracted, its shortest distance is final.

🔗

What is Edge Relaxation?

For every neighbour of the current vertex, the algorithm checks whether travelling through the current vertex offers a shorter route. If so, it "relaxes" the edge by updating the neighbour's distance and previous vertex.

⏱

Complexity

Time: O((V + E) log V)
Space: O(V)
